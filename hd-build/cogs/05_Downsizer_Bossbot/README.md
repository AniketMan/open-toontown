# 05_Downsizer_Bossbot HD build (suit B, code `ds`, scale 4.5 / 5.29)

Everything here runs in place: the scripts point at this folder, not at a scratch directory (a restart wiped the
scratch folder on 2026-11-14). Step order as in `../03_Yesman_Bossbot/README.md`; `run.py` rebuilds, rigs and renders
check views into `work/`.

Sheets read: all five (see `../REFERENCE_INDEX.md`). Measured sheet: new-turnaround, 576 px = 6.08 game units.
The frown is the arched top edge of the mouth cassette, cut wider than a panel line; the line under the nose is a
slit in the face shell that turns up at each end. Limbs are the Pencil Pusher's suit B limbs with thinner sleeves
and legs. `work/gen.py` shows how build.py and rig.py were put together from the 02 and 04 folders.
