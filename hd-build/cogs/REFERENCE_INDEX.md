# Reference image index

The `exec-*.png` files in this folder are the concept sheets, unnamed. Named copies of all but two are in
`~/Documents/Codex/2026-11-12/new-chat/<kind>/`. Matched by file content. Look at EVERY sheet listed for a cog before
building it: the sheets disagree in places (ears, straps, mouth), and the majority reading is the one to build.

Kinds: new-turnaround (the one to measure; states the height), robotic-turnaround-v2 (same views, more robotic detail),
modeling-blueprint-turnaround (exploded parts), robotic-blueprint-turnaround (engineering sheet with head detail),
head-breakdown (head shell, mouth cassette, jaw pivot).

Head breakdowns for all 40 slots, named, are also in `~/Downloads/robot-heads/<slot>_head-breakdown.png` (delivered 2026-11-14).
They fill the breakdowns missing below for slots 20-40, and the one for 13 Back Stabber there REPLACES the older file listed here.
