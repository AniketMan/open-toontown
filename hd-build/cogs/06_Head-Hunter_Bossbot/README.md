# 06_Head-Hunter_Bossbot HD build (suit A, code `hh`, scale 6.5 / 6.06)

Runs in place, like `../05_Downsizer_Bossbot/`. Sheets read: all five; measured sheet: new-turnaround, 539 px = 7.5
game units. Four of the five sheets show ringed ear discs (the measured one shows plain ears), so he has the discs.
Limbs are the Yesman's suit A limbs with thicker sleeves; the torso's shoulders have to reach the shoulder joints
(x 1.79 game), or the arms hang detached. Head: squared section (superellipse power 3), so seam gaps are set as a
distance (`th_of`), not an angle. `work/gen.py` shows how build.py and rig.py were assembled.
